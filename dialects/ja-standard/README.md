# COIL:ja-standard — 日本語標準方言

> 「考える言葉で、シナリオを書こう。」

**状態：** 公式方言。標準ディストリビューションに含まれる。

この方言は、すべてのCOIL構文を自然な日本語に対応づける。各キーワードは、プログラミング経験がなくても、英語を介さなくても、日本語話者にとって直感的に理解できるように選ばれている。漢字とひらがなだけで構成され、カタカナ（外来語）は使わない。

---

## 設計原則

1. **名詞形。** 操作符は名詞形を使う：定義、思考、実行。日本語のUIボタンと同じ形式。命令形（定義しろ）は乱暴に聞こえ、動詞辞書形（定義する）は冗長になる。名詞形は端的で、かつ自然。

2. **日常語。** 専門用語を避け、日常の日本語を使う。`送信` はメールやLINEの送信ボタンと同じ言葉。`最大` は「最大10分」のように自然に読める。`道具` は「ツール」の大和言葉。

3. **漢字とひらがなの使い分け。** 内容語は漢字（思考、実行、送信）、機能語はひらがな（として、まで、から、もし）。これは日本語の自然な表記法そのもの。カタカナがないのは、すべてのキーワードが日本語の固有語であることの証左。

4. **類別の手がかり。** 語の意味が操作の性質を暗示する：阻止型（受信、待機）、起動型（思考、実行、送信）、即時型（定義、変更）。

## Core操作符

| ID | JA | 意味 |
|---|---|---|
| `Op.Actors` | `参加者` | プロトコルの参加者を宣言する。シナリオの中で誰が動くか。 |
| `Op.Tools` | `道具` | 利用可能な道具を宣言する。エージェントが何を使えるか。 |
| `Op.Define` | `定義` | 名前つきの値を新規作成する。数学の定義と同じ。 |
| `Op.Set` | `変更` | 既存の値を変更する。`定義` との違い——値はすでに存在している。 |
| `Op.Receive` | `受信` | 環境から値をブロッキングで受け取る。プロトコルは環境が値を提供するまで停止する。 |
| `Op.Think` | `思考` | LLMの認知ステップを起動する。モデルが問いを受け取り、考える。 |
| `Op.Execute` | `実行` | 道具を呼び出す。単発呼び出しとインタラクティブセッションの両方を含む。 |
| `Op.Send` | `送信` | チャンネルにメッセージを送る。日本語では「メッセージを送る」「LINEで送る」が自然——「書く」ではなく「送る」。 |
| `Op.Wait` | `待機` | 同期点。約束が果たされるまでブロッキングで待つ。 |
| `Op.Exit` | `終了` | プロトコルを終結する。一行、引数なし。 |
| `Kw.End` | `以上` | ブロックを閉じる。各ブロック操作符は `以上` で終わる。日本語で報告や発表の末尾に使う「以上」——「この部分はここまで」。 |

|---|---|---|

| ID | JA | 意味 |
|---|---|---|

| ID | JA | 意味 |
|---|---|---|

| `Mod.Await` | `待受` | 応答待ちの方針。`待受 いずれか` ——少なくとも一つの返信を待ち受ける。`待機`（操作符）とは別語——注釈を参照。 |
| `Mod.Timeout` | `最大` | タイムアウト。`最大 10分` ——10分後に打ち切る。 |

|---|---|---|

|---|---|---|

## 文脈依存の解決

`最大` は二つの抽象IDに対応する。操作符の文脈がどちらかを一意に決定する：

| キーワード | 文脈 | 抽象ID |
|---|---|---|
| `最大` | `送信` または `待機` の中 | `Mod.Timeout` |
| `最大` | `反復` の中 | `Mod.Limit` |

「最大10分」（タイムアウト）と「最大5回」（反復上限）——一つの自然な日本語で二つの場面を覆う。

## 注釈

**なぜブロック終端に `以上` を使うのか？**
`終了` はプロトコル全体を終結する——最終的で不可逆。`以上` はブロックを閉じる——局所的で繰り返し現れる。日本語で報告・発表・注文の末尾に「以上です」と言う習慣がある。すべての方言の中で、日本語だけがこの文化的慣用句をブロック終端に使う。

**なぜ `送信` であって `書く` ではないのか？**
他の方言（ロシア語 НАПИШИ、ドイツ語 SCHREIBE、フランス語 ÉCRIS）は「書く」を選んだ——それらの言語では「私に書いて」と言うから。だが日本語では「メッセージを送る」「LINEで送る」「メールを送信する」——動詞は「送る」であって「書く」ではない。中国語の `发送` と同じ理由で、`送信` が日本語話者の実際の言語習慣を反映する。

**なぜ `として`、`まで`、`から` をキーワードに使うのか？**
これらは日本語の助詞・接続助詞であり、本来は名詞の後に置く（後置）。COILの構文ではキーワードが先頭に来る（前置）。この語順はCOILの統一構文規則によるもので、すべての方言が同じ制約を受ける。前置の位置でも、意味は即座に理解できる——`として` は「〜として」、`まで` は「〜まで」、`から` は「〜から」。
